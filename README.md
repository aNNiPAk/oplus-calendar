# OPlus calendar

Стоковый APK `com.oplus.calendar` для обновлений через Obtainium.

Прошивки OPPO, OnePlus и Realme обрабатывает [центральный бот](https://github.com/aNNiPAk/oplus-stock-app-bot): каждый раздел извлекается один раз сразу для семи приложений. Этот канал не скачивает OTA — он получает нужный APK из завершённого общего набора.

Выбор производится по Android `versionCode`. Русский APK публикуется основным релизом; более свежий без русского, но с английским или неопределённым языком — experimental prerelease, который не заменяет Latest. Сертификат проверяется и записывается для диагностики, без требования совпадения с предыдущим релизом. APK не изменяется и не переподписывается.

Канал повторно проверяет хеш, подпись, package, версию и язык перед публикацией. Понижение версии не выполняется. Сообщения в наборе — OPlus `com.android.mms`, а не Google Messages.

Проверка набора выполняется каждые шесть часов. Для ручного запуска: Actions → Publish OPlus calendar from suite → Run workflow; dry-run по умолчанию проверяет APK без публикации. Центральный workflow Update stock suite должен предварительно опубликовать завершённый набор.

Подписывайтесь в Obtainium на этот репозиторий. Experimental требует включения prerelease; наличие русского и корректной подписи не гарантирует совместимость с конкретной прошивкой телефона.
